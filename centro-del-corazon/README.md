# Centro del Corazón · landing

Hecha sobre la plantilla **Amber** (`Miiles01/ideas/templates/amber`), en HTML/CSS/JS plano (GSAP + ScrollTrigger + Lenis por CDN).

## Fotos
Cada imagen busca primero un archivo en `img/`. Si no existe, usa una foto de respaldo de Unsplash, y si tampoco carga, se queda un color sólido de la marca.
Para poner las fotos del cliente, súbelas con estos nombres:

| Archivo | Dónde aparece |
|---|---|
| `img/hero.jpg` | Portada (horizontal, 2000px) |
| `img/luz.jpg` | Imagen a todo el ancho "Respira. Aquí empieza todo" |
| `img/manos.jpg` | Miniatura vertical sobre esa imagen |
| `img/curso-basico.jpg` | Curso Básico del Corazón (vertical 2:3) |
| `img/curso-milagros.jpg` | Un Curso de Milagros (vertical 2:3) |
| `img/naturaleza.jpg` | Imagen "Cuando el corazón se aquieta" |
| `img/ananda.jpg` | Retrato de Ananda Mariscal (vertical 2:3, sin respaldo) |
